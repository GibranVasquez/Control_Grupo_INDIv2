# GI Control Combustible

App de control de combustible en obra (Grupo INDI). Monorepo dividido en:

- [`frontend/`](frontend/) — app Flutter (chofer / administrativo / finanzas). Ver [`frontend/README.md`](frontend/README.md).
- [`backend/`](backend/) — API REST propia (Node.js + TypeScript + Express + Prisma), autenticada por JWT (propiedad del equipo de backend). Ver [`backend/README.md`](backend/README.md).
- [`design/`](design/) — handoff de diseño (prototipo HTML de referencia, screenshots, tokens). No es código de producción.
